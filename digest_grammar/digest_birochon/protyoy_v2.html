ধাতুর (কাজের মূলের) সাথে যে প্রত্যয় বসে — কৃদন্ত পদ তৈরি হয়

অক / ণক

নিয়ম

শব্দের শেষে 'অক' থাকলে মূল প্রত্যয় হবে 'অক' বা 'ণক' (ণ্বুল্)। ধাতু + অক = বিশেষ্য।

কারণ

সংস্কৃতে আসল প্রত্যয়টি 'ণক'। এর 'ণ' আর 'ক' ব্যাকরণের নিয়মে বাদ পড়ে, শুধু 'অ' থাকে — আর 'ণ' থাকার কারণে ধাতুর স্বর বড় হয় (কৃ→কার, নী→নায়)। কাজ যে করে তার পরিচয় তৈরি হয় বলে এটি বিশেষ্য।

উদাহরণ
কারককৃ + অক
নায়কনী + অক
পাঠকপঠ্ + অক
দর্শকদৃশ্ + অক
গায়কগৈ + অক
লেখকলিখ্ + অক
কাজের কর্তা = অক = বিশেষ্য

অনীয়

নিয়ম

শব্দের শেষে 'নীয়' বা 'নীয়া' থাকলে মূল প্রত্যয় 'অনীয়'। ধাতু + অনীয় = বিশেষণ।

কারণ

সংস্কৃত প্রত্যয় 'অনীয়র্'; শেষের 'র্' বাদ পড়ে। কাজ 'করার যোগ্য বা উচিত' বোঝায়, অর্থাৎ অবস্থা/যোগ্যতা, তাই বিশেষণ।

উদাহরণ
করণীয়কৃ + অনীয়
দর্শনীয়দৃশ্ + অনীয়
শ্রবণীয়শ্রু + অনীয়
যোগ্যতা = অনীয় = বিশেষণ

তৃ / তৃচ্

নিয়ম

শব্দের শেষে 'তা' থাকলে মূল প্রত্যয় 'তৃ' বা 'তৃচ্'। ধাতু + তৃ = বিশেষ্য।

কারণ

আসল রূপ 'দাতৃ', 'নেতৃ', 'কর্তৃ'; প্রথমা বিভক্তির একবচনে উচ্চারণে হয়ে যায় দাতা, নেতা, কর্তা। কাজটি যে করে সেই মানুষের পরিচয়, তাই বিশেষ্য।

উদাহরণ
দাতাদা + তৃ
কর্তাকৃ + তৃ
নেতানী + তৃ
জ্ঞাতাজ্ঞা + তৃ
শেষে 'তা' দেখলে মূল 'তৃ'

শানচ্

নিয়ম

শব্দের শেষে 'মান' থাকলে মূল প্রত্যয় 'শানচ্'। ধাতু + মান = বিশেষণ (বর্তমান শব্দটি বিশেষ্য ও বিশেষণ দুটোই)।

কারণ

'শানচ্'-এর 'শ্' ও 'চ্' বাদ পড়ে 'আন' থাকে, যা ধাতুর সাথে 'মান' রূপ নেয়। কাজ 'এখন চলছে' এই অবস্থা বোঝায়, তাই বিশেষণ। 'বর্তমান' সময় বোঝালে বিশেষণ, কালের নাম হিসেবে বিশেষ্য।

উদাহরণ
চলমানচল্ + শানচ্
বর্ধমানবৃধ্ + শানচ্
বর্তমানবৃৎ + শানচ্
মানের আগে ধাতু = শানচ্ · মানের আগে নাম = মতুপ্

য (ণ্যৎ / যৎ)

নিয়ম

শব্দের শেষে 'র্য' বা 'য্য' থাকলে মূল প্রত্যয় 'য'। ধাতু + য = বিশেষণ; বিশেষণ + য = বিশেষ্য।

কারণ

'ণ্যৎ' ও 'যৎ' প্রত্যয়ের বাড়তি অংশ বাদ পড়ে শুধু 'য' থাকে। ধাতুর সাথে বসলে 'করার যোগ্য' (বিশেষণ)। গুণবাচক শব্দের সাথে বসলে ভাবের নাম (বিশেষ্য)। 'বাচ্য' (Voice) অর্থে বিশেষ্য।

উদাহরণ
কার্যকৃ + য
ভোজ্যভুজ্ + য
লভ্যলভ্ + য
সৌন্দর্যসুন্দর + য
ধৈর্যধীর + য
ধাতু+য = বিশেষণ · বিশেষণ+য = বিশেষ্য

অ / অল্

নিয়ম

শব্দের শেষে 'অয়' থাকলে মূল প্রত্যয় 'অ' বা 'অল্'। ধাতু + অ = বিশেষ্য।

কারণ

'অল্'-এর 'ল্' বাদ পড়ে 'অ' থাকে। ই/ঈ-কারান্ত ধাতুর সাথে 'অ' যোগ হলে সন্ধিতে ই/ঈ বদলে 'অয়' হয় (জি→জয়, ভী→ভয়)। কাজের ভাব বা ফলের নাম বোঝায়, তাই বিশেষ্য। ব্যতিক্রম: হন্ + অল্ = বধ।

উদাহরণ
জয়জি + অ
ভয়ভী + অ
বিনয়বি + নী + অ
বধহন্ + অল্
অয় = অ/অল্ = বিশেষ্য

ক্ত

নিয়ম

শব্দের শেষে ত / ক্ত / ন্ত / দ্ধ / গ্ধ থাকলে মূল প্রত্যয় 'ক্ত'। (সাধারণত বিশেষণ)

কারণ

'ক্ত' ধাতুর শেষ বর্ণের সাথে সন্ধি করে নানা চেহারা নেয়। কাজ 'শেষ হয়ে গেছে' এই অবস্থা বোঝায়, তাই সাধারণত বিশেষণ।

উদাহরণ
গতগম্ + ক্ত
মুক্তমুচ্ + ক্ত
শান্তশম্ + ক্ত
যুদ্ধযুধ্ + ক্ত
মুগ্ধমুহ্ + ক্ত
ই-কার ছাড়া ত/ক্ত/ন্ত/দ্ধ/গ্ধ = ক্ত

ক্তি

নিয়ম

শব্দের শেষে তি / ক্তি / ন্তি / ষ্টি ইত্যাদি থাকলে মূল প্রত্যয় 'ক্তি'। ধাতু + ক্তি = বিশেষ্য।

কারণ

০৭-এর মতোই, শুধু এখানে শেষে ই-কার আছে। 'ক্তি' কাজের ভাব বা প্রক্রিয়ার নাম তৈরি করে, তাই সবসময় বিশেষ্য।

উদাহরণ
গতিগম্ + ক্তি
মুক্তিমুচ্ + ক্তি
শান্তিশম্ + ক্তি
দৃষ্টিদৃশ্ + ক্তি
ভক্তিভজ্ + ক্তি
ই-কারওয়ালা তি/ক্তি/ন্তি/ষ্টি = ক্তি = বিশেষ্য

তব্য

নিয়ম

শব্দের শেষে 'তব্য' থাকলে প্রত্যয়ও 'তব্য'। ধাতু + তব্য = বিশেষণ।

'তব্য' কাজের উচিত বা আবশ্যকতা বোঝায় — বৈশিষ্ট্য বা অবস্থা, তাই বিশেষণ। রূপ অপরিবর্তিত থাকে।

নিয়ম

শব্দের শেষে 'বর' থাকলে প্রত্যয়ও 'বর'। ধাতু + বর = বিশেষ্য।

ঘঞ্

নিয়ম

বাস, ক্রোধ, ভেদ, যোগ, খেদ — এই শব্দগুলোর প্রত্যয় 'ঘঞ্'।

কারণ

'ঘঞ্'-এর 'ঘ' ও 'ঞ' বাদ পড়ে শুধু 'অ' থাকে, যা ধাতুর ভেতরের স্বরকে বড় করে (বৃদ্ধি/গুণ)। তাই শব্দের শেষে 'ঘঞ্' শোনা যায় না, কিন্তু ধাতুর স্বর বদলে যায় (বস্→বাস, ক্রুধ্→ক্রোধ, ভিদ্→ভেদ, যুজ্→যোগ)।

অ (অণ্ / ষ্ণ)

নিয়ম

শব্দের শেষে 'অব' বা 'অ' থাকলে মূল প্রত্যয় 'ষ্ণ' বা 'অ'। বিশেষ্য + অ = বিশেষণ।

কারণ

'অণ্'-এর 'ণ্' বাদ পড়ে 'অ' থাকে এবং প্রথম স্বর বড় হয়। মূল শব্দের শেষে উ/ঊ থাকলে তা 'অ'-এর সাথে মিলে 'অব' হয় (মনু→মানব, গুরু→গৌরব)।

উদাহরণ
মানবমনু + অ
গৌরবগুরু + অ
শৈবশিব + অ
বৌদ্ধবুদ্ধ + অ
শুরুতে বৃদ্ধি + শেষে অব/অ

বিশেষণ

বিন্ (বী)

নিয়ম

শব্দের শেষে 'বী' থাকলে মূল প্রত্যয় 'বিন্'। বিশেষ্য + বিন্ = বিশেষণ।

কারণ

সংস্কৃতে রূপ 'মেধাবিন্'; বাংলায় শেষের 'ন্' লোপ পায় এবং হ্রস্ব-ই দীর্ঘ-ঈ হয়ে 'বী' দাঁড়ায়। বিশেষ গুণ নিজের মধ্যে থাকা বোঝায়, তাই বিশেষণ।

উদাহরণ
মেধাবীমেধা + বিন্
মায়াবীমায়া + বিন্
যশস্বীযশঃ + বিন্
আছে = বী = বিশেষণ

বতুপ্ (বৎ)

নিয়ম

শব্দের শেষে 'বান' থাকলে মূল প্রত্যয় 'বতুপ্' বা 'বৎ'। বিশেষ্য + বান = বিশেষণ।

কারণ

'বতুপ্'-এর 'প্' বাদ পড়ে রূপ হয় 'বৎ'; প্রথমা বিভক্তির একবচনে তা 'বান' হয়। যার যা আছে (দয়া, ধন, গুণ), সে সেই গুণবান — অবস্থা প্রকাশ, তাই বিশেষণ।

উদাহরণ
দয়াবানদয়া + বতুপ্
গুণবানগুণ + বতুপ্
ধনবানধন + বতুপ্
বান = বতুপ্
০৬
বিশেষণ

মতুপ্ (মৎ)

নিয়ম

শব্দের শেষে 'মান' থাকলে মূল প্রত্যয় 'মতুপ্' বা 'মন্'। বিশেষ্য + মান = বিশেষণ।

কারণ

'বতুপ্'-এর ভাই-প্রত্যয়। 'প্' বাদ পড়ে 'মৎ', প্রথমায় 'মান'। কৃৎ প্রত্যয়ের 'শানচ্'-এর সাথে গুলিয়ে ফেলবেন না: মানের আগে ধাতু থাকলে শানচ্ (চলমান), নাম শব্দ থাকলে মতুপ্ (বুদ্ধিমান)।

উদাহরণ
বুদ্ধিমানবুদ্ধি + মতুপ্
শক্তিমানশক্তি + মতুপ্
শ্রীমানশ্রী + মতুপ্
মানের আগে নাম = মতুপ্

বিশেষ্য

ষ্যঞ্ (য)

নিয়ম

শব্দের শেষে 'র্য' বা য-ফলা থাকলে মূল প্রত্যয় 'ষ্যঞ্' বা 'য'। বিশেষণ + য = বিশেষ্য।

কারণ

'ষ্যঞ্'-এর 'ষ্' ও 'ঞ্' বাদ পড়ে 'য' থাকে, প্রথম স্বর বড় হয়। গুণবাচক শব্দকে ভাবের নামে বদলে দেয় (সুন্দর→সৌন্দর্য), তাই বিশেষ্য।

উদাহরণ
সৌন্দর্যসুন্দর + য
প্রাচুর্যপ্রচুর + য
মাধুর্যমধুর + য
গুণ → ভাবের নাম (য)

য (ষ্যঞ্ / যঞ্)

নিয়ম

শব্দের শেষে য-ফলা থাকলে মূল প্রত্যয় 'য'। (বিশেষ্য)

কারণ

'য' আগের বর্ণের সাথে জুড়ে য-ফলা হয় এবং প্রথম স্বর বড় হয়। বিশেষণ বা গুণের ভাব/অবস্থাকে নাম দেয়, তাই বিশেষ্য।

উদাহরণ
সাম্যসম + য
তারল্যতরল + য
কাব্যকবি + য
কাঠিন্যকঠিন + য
ভাব/অবস্থার নাম
০৯

ইমন

নিয়ম

শব্দের শেষে 'ইমা' থাকলে মূল প্রত্যয় 'ইমন'। (বিশেষ্য)

কারণ

সংস্কৃতে 'ইমনিচ্' / 'ইমন্'; প্রথমার একবচনে শেষের 'ন্' লোপ পেয়ে 'ইমা' হয়। গুণ বা রঙের ভাব ও সৌন্দর্যের নাম বোঝায়, তাই বিশেষ্য।

উদাহরণ
মহিমামহৎ + ইমন
নীলিমানীল + ইমন
গরিমাগুরু + ইমন
লালিমালাল + ইমন
ইমা = ইমন

বিশেষণ

ইত (ইতচ্)

নিয়ম

শব্দের শেষে 'ইত' থাকলে প্রত্যয়ও 'ইত'। বিশেষ্য + ইত = বিশেষণ।

কারণ

'ইতচ্'-এর 'চ্' বাদ পড়ে 'ইত' থাকে। শব্দের শুরুতে কোনো বৃদ্ধি হয় না। 'যুক্ত', 'জাত' বা 'প্রাপ্ত' বোঝায়, অবস্থা প্রকাশ করে, তাই বিশেষণ।

উদাহরণ
ব্যথিতব্যথা + ইত
পুষ্পিতপুষ্প + ইত
তরঙ্গিততরঙ্গ + ইত
দুঃখিতদুঃখ + ইত
ইত = অপরিবর্তিত = বিশেষণ

নিয়ম

শব্দের শেষে 'ইল' থাকলে প্রত্যয়ও 'ইল'। বিশেষ্য + ইল = বিশেষণ।

কারণ

'ইলচ্'-এর 'চ্' বাদ পড়ে 'ইল' থাকে। 'কিছু দিয়ে ভরা' বা 'যুক্ত' বোঝায়, তাই বিশেষণ। শব্দের শুরুতে স্বর বদলায় না।

উদাহরণ
পঙ্কিলপঙ্ক + ইল
ফেনিলফেনা + ইল

তা (তাক্)

নিয়ম

শব্দের শেষে 'তা' থাকলে প্রত্যয়ও 'তা'। বিশেষণ + তা = বিশেষ্য।

কারণ

খুবই সাধারণ প্রত্যয়; কোনো বর্ণ বাদ পড়ে না, শুরুতে বৃদ্ধিও হয় না। ভাব, অবস্থা বা ধর্ম বোঝায়, তাই ভাববাচক বিশেষ্য।

উদাহরণ
মধুরতামধুর + তা
সাধুতাসাধু + তা
বন্ধুতাবন্ধু + তা
চঞ্চলতাচঞ্চল + তা
ভাব = তা

ত্ব (ত্বন্)

নিয়ম

শব্দের শেষে 'ত্ব' থাকলে প্রত্যয়ও 'ত্ব'। (বিশেষ্য)

কারণ

'তা'-এর জোড়া প্রত্যয়, অর্থও একই (ভাব, অবস্থা, ধর্ম)। চাইলে একই শব্দের সাথে দুটোই বসতে পারে (বন্ধুতা, বন্ধুত্ব)। ভাবের নাম, তাই বিশেষ্য।

উদাহরণ
কবিত্বকবি + ত্ব
মনুষ্যত্বমনুষ্য + ত্ব
গুরুত্বগুরু + ত্ব
মহত্ত্বমহৎ + ত্ব
বন্ধুত্ববন্ধু + ত্ব
তা ও ত্ব = একই অর্থ

অঞ্জলি

নিয়ম

শব্দের শেষে 'অঞ্জলি' থাকলে প্রত্যয়ও 'অঞ্জলি'। (বিশেষ্য)

কারণ

কিছু পূর্ণ শব্দও প্রত্যয়ের মতো শেষে বসে নতুন শব্দ গড়ে — 'অঞ্জলি' তেমনই। আগের শব্দের শেষের অ/আ-র সাথে অঞ্জলির 'অ' মিলে 'আ' হয়। 'নিবেদন' অর্থের নাম, তাই বিশেষ্য।

উদাহরণ
গীতাঞ্জলিগীত + অঞ্জলি
শ্রদ্ধাঞ্জলিশ্রদ্ধা + অঞ্জলি
অঞ্জলি = নিবেদন
